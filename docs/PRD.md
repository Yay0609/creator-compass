# PRD — 创作罗盘

- 版本：v1.0（P0 冻结）
- 产品名：创作罗盘（creator-compass）
- 形态：响应式 Web（先做桌面 + 移动浏览器，不做小程序 / App）

## 1. 产品定位

面向小红书 / B站 / 抖音 **0–1 万粉新手创作者** 的一站式 AI 助手，覆盖内容生产的最小闭环：

**今天发什么 → 怎么发 → 发完为什么行 / 不行**

## 2. 目标用户

- 想做账号但不知道发什么、标题怎么写、发完不会复盘的新手
- 有更新意愿，但缺少方法，也缺少正反馈

## 3. 核心痛点

| # | 痛点 | 表现 |
| --- | --- | --- |
| 1 | 选题靠感觉 | 不知道什么内容有流量，只能跟风或自嗨 |
| 2 | 标题 / 开头 / 脚本不会写 | 点击率低，完播差 |
| 3 | 发完不会复盘 | 不知道爆款为什么爆、扑街为什么扑 |
| 4 | 更新难坚持 | 缺少数据反馈，正反馈断裂 |

## 4. 北极星指标

**周完成闭环次数** = 一周内完成「生成选题 → 生成脚本 → 录入数据 → 拿到复盘」的账号数。

MVP 目标：

- 新用户首次会话 15 分钟内跑通一次完整闭环
- 次周留存 ≥ 25%

## 5. 用户故事

| ID | 用户故事 | 验收要点 | 阶段 |
| --- | --- | --- | --- |
| US-01 | 我用邮箱注册并创建第一个账号画像（平台 / 赛道 / 人设 / 粉丝量） | 未建画像不能生成内容 | P1 |
| US-02 | 我一键拿到 5 条可跟选题，每条带推荐理由与参考方向 | 5 条、含理由、可收藏、可换一批 | P2 |
| US-03 | 我把一条选题转成标题 + 开头 + 脚本框架 + 标签 | 5 个标题候选、1 个开头钩子、分段脚本、5–10 个标签 | P3 |
| US-04 | 我手动录入或粘贴 CSV 作品数据 | 单条录入 + CSV 粘贴 + 列映射预览 + 错误行提示 | P4 |
| US-05 | 我让 AI 告诉我哪条好、为什么、下一步怎么做 | 单篇 + 批量复盘，输出结论 / 归因 / 3–5 条下一步动作 | P4 |
| US-06 | 我回看历史选题、脚本、复盘 | 三个列表页 + 详情页，支持删除 / 归档 | P2–P4 |
| US-07 | 我知道今天还能用几次 AI | 顶部展示剩余额度；超额给出明确提示而非静默失败 | P2 |
| US-08 | 我退出登录 / 注销账号 | 注销后数据级联删除 | P1 / P5 |

## 6. MVP 范围（做）

- 邮箱密码认证 + httpOnly Cookie 会话（自建 Session 表，不用 NextAuth）
- 账号画像（数据模型支持多账号；MVP UI 只做单默认画像）
- 热点选题推荐（5 条 / 次，流式输出）
- 标题与脚本生成（标题候选、开头钩子、分段框架、标签、封面文案）
- 作品数据录入（手动 + CSV 粘贴）+ AI 复盘
- 历史资产库（选题 / 脚本 / 复盘）
- 每用户配额（选题 10 / 脚本 10 / 复盘 5，每月）+ 每日防刷上限 `AI_DAILY_LIMIT=20`
- 响应式 Web（375px 起可用）

## 7. 非目标（明确不做）

- 不做爬虫、不抓取平台数据、**不宣称实时热榜**
- 不做自动发布、不接入平台 OAuth、不采集平台账号密码或 Cookie
- 不做社区 / 关注 / 私信 / 评论
- 不做小程序、不做原生 App
- 不做付费订阅（MVP 只记录用量）
- 不做团队协作、不做多语言（中文 only）、不做视频剪辑与素材生成
- 不做复杂数据可视化（仅基础趋势与对比）

## 8. 关键指标与埋点（P5 接入）

- 生成次数（按 feature：topic / script / review）
- 闭环完成率（四个步骤的漏斗）
- 配额命中率与失败率
- AI 调用耗时与 token 成本（`AiCallLog`）
